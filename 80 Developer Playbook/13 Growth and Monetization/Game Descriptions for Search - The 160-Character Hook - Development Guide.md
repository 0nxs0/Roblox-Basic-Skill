## Source-grounded context
Most developers write the description last, in a hurry, as a list of controls and hashtags. But the description is what Google, Bing and DuckDuckGo index, what shows under your title on mobile before "read more", and part of how a searching player decides. Since Creator Rewards pays Audience Expansion for new users who search your game's name and play, being findable by name is now worth Robux too. Roblox...

## Apply it

- **Maintain it:** Separate tuning data from behavior, record assumptions, and provide cleanup or rollback before connecting more systems.

## Validate before shipping
- **Expected path:** Build one small feature using Game Descriptions for Search - The 160-Character Hook and record setup and expected result.
- **Boundary case:** Test missing, invalid, repeated, delayed, or interrupted input where relevant.
- **Integration:** Test with neighboring systems and at target device/player scale.
- **Acceptance check:** Compare conversion with satisfaction and test no-spend progression.
