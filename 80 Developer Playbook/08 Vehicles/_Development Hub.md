# 08 Vehicles — Development Hub

This hub contains 74 new development companions, one for each existing Markdown note in **08 Vehicles**. Each links to its source and adds implementation and validation guidance.

## Focus
Use this material to tune vehicle handling repeatably.

## Build loop
1. Set handling targets and tune one parameter at a time on a fixed course.
2. Account for network ownership, collisions, seat changes, uneven ground, and touch input.
3. Test stability, collisions, recovery, and multiple clients.
