## Focus
Use this material to assemble small loops from understood parts.

## Build loop
1. Build one playable loop, separate configuration from behavior, and document replacement points.
2. Check dependencies, licenses, authority, and lifecycle before reuse.
3. Run in a clean place and swap one component safely.
