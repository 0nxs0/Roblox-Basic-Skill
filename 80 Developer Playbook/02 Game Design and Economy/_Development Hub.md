# 02 Game Design and Economy — Development Hub

This hub contains 118 new development companions, one for each existing Markdown note in **02 Game Design and Economy**. Each links to its source and adds implementation and validation guidance.

## Focus
Use this material to make fair, measurable player loops.

## Build loop
1. Map action, feedback, reward, and next choice; define cost, pacing, and a success measure.
2. Check exploits, runaway rewards, and no-spend fairness.
3. Test first play, repeat play, and edge-case balances.
