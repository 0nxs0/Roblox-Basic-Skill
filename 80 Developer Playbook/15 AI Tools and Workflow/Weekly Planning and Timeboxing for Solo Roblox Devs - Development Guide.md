## Source-grounded context
Solo Roblox projects rarely die from one hard bug; they die from a slow drift where every week adds features and nothing ships. A light weekly plan with fixed time boxes fixes that, because it forces you to choose. This note is a planning rhythm sized for someone working evenings and weekends, using the vault you already have. - **Maintain it:** Separate tuning data from behavior, record assumptions, and provide cleanup or rollback before connecting more systems.

## Validate before shipping
- **Expected path:** Build one small feature using Weekly Planning and Timeboxing for Solo Roblox Devs and record setup and expected result.
- **Boundary case:** Test missing, invalid, repeated, delayed, or interrupted input where relevant.
- **Integration:** Test with neighboring systems and at target device/player scale.
- **Acceptance check:** Check diffs, API versions, error paths, and tests.
