## Source-grounded context
A SurfaceGui puts normal 2D UI (text, images, buttons) onto the face of a part. It is how you make shop signs, a "Stage 12" marker, a round timer on a wall, a top-players board in the lobby, or a computer screen players can click. It uses the same TextLabels and Frames you already know from First GUI Button - ScreenGui, TextButton and Activated, so the only new things are which face, how sharp, how bright, and...
