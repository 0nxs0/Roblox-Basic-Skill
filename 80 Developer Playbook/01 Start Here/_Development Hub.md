# 01 Start Here — Development Hub

This hub contains 78 new development companions, one for each existing Markdown note in **01 Start Here**. Each links to its source and adds implementation and validation guidance.

## Focus
Use this material to connect learning to playable results.

## Build loop
1. Choose a learning goal and prove it in a small vertical slice; record prerequisites and next steps.
2. Practice references in a disposable place and note version assumptions.
3. Can a new developer produce a testable feature?
