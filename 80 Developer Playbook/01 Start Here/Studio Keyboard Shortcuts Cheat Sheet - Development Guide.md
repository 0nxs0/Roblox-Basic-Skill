# Studio Keyboard Shortcuts Cheat Sheet — Development Guide

New practical guidance for [[01 Start Here/Community Knowledge/Studio Keyboard Shortcuts Cheat Sheet|Studio Keyboard Shortcuts Cheat Sheet]]. This companion adds a build and validation plan; use the linked source for full reference detail.

## Source-grounded context
Shortcuts are the cheapest speed-up in Roblox development. The ones below are the defaults listed across the official Studio pages (Windows first, Mac in brackets where it differs). Every binding can be changed, and actions with no default can be bound, in File > Customize Shortcuts. Print this or pin it beside Studio for your first week.
**Useful source sections:** Camera (click the viewport first), Building and selection, Explorer.

## Validate before shipping
- **Expected path:** Build one small feature using Studio Keyboard Shortcuts Cheat Sheet and record setup and expected result.
- **Boundary case:** Test missing, invalid, repeated, delayed, or interrupted input where relevant.
- **Integration:** Test with neighboring systems and at target device/player scale.
- **Acceptance check:** Can a new developer produce a testable feature?
