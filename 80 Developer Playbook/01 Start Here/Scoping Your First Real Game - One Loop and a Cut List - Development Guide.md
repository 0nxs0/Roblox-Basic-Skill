# Scoping Your First Real Game - One Loop and a Cut List — Development Guide

## Source-grounded context
After a few practice obbies, most beginners announce their first "real" game: an open-world RPG with guilds, trading, pets, vehicles, a story mode and 40 weapons. Months later it is half-built and abandoned. The skill that separates shipped games from dead folders is scope: deciding what not to build. This note gives a beginner-sized method: define one loop, size every feature in days, cut until the first version...
**Useful source sections:** Step 1: write the loop in one sentence, Step 2: list every feature, then size it, Step 3: cut to a four-to-six-week version 1.

- **Project risk:** Practice references in a disposable place and note version assumptions.

## Validate before shipping
- **Expected path:** Build one small feature using Scoping Your First Real Game - One Loop and a Cut List and record setup and expected result.
- **Boundary case:** Test missing, invalid, repeated, delayed, or interrupted input where relevant.
- **Integration:** Test with neighboring systems and at target device/player scale.
- **Acceptance check:** Can a new developer produce a testable feature?
