# First Sound - Background Music and a Click Sound — Development Guide

New practical guidance for [[01 Start Here/Community Knowledge/First Sound - Background Music and a Click Sound|First Sound - Background Music and a Click Sound]]. This companion adds a build and validation plan; use the linked source for full reference detail.

## Source-grounded context
Sound is the cheapest polish there is: a soft music loop, a click on buttons and a "ding" on coin pickup make a beginner game feel finished. Roblox has two audio systems: the classic Sound object (simple, perfect for a first game) and the newer Audio API (AudioPlayer, AudioEmitter, wires) for advanced mixing. This note uses Sound objects for the three sounds every first game needs.
**Useful source sections:** Where a Sound lives decides how it plays, Get an audio ID, 1. Background music (2 minutes).

## Validate before shipping
- **Expected path:** Build one small feature using First Sound - Background Music and a Click Sound and record setup and expected result.
- **Boundary case:** Test missing, invalid, repeated, delayed, or interrupted input where relevant.
- **Integration:** Test with neighboring systems and at target device/player scale.
- **Acceptance check:** Can a new developer produce a testable feature?
