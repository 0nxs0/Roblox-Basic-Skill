## Source-grounded context
The tycoon loop (a machine makes items, a belt carries them, a collector turns them into cash, cash buys more machines) is one of the most popular Roblox genres and a great second project after an obby. The core is only three small scripts. This note builds a single working dropper line with the pieces you will reuse in every tycoon: spawning parts on a timer, a moving conveyor without scripts, storing value in...
**Useful source sections:** Build the line (5 minutes), Conveyor: no script needed, Dropper script (inside `Tycoon`).
