# Explorer, Properties and Toolbox - Beginner Field Guide — Development Guide

New practical guidance for [[01 Start Here/Community Knowledge/Explorer, Properties and Toolbox - Beginner Field Guide|Explorer, Properties and Toolbox - Beginner Field Guide]]. This companion adds a build and validation plan; use the linked source for full reference detail.

## Source-grounded context
These three windows are where you spend most of your time outside the viewport. Explorer answers "what exists and where", Properties answers "how is it set up", and Toolbox answers "where do I get assets". Beginners lose hours because a script sits in the wrong Explorer folder, or because a property they never noticed (like `Anchored`) is wrong, so it pays to learn these windows on purpose.
**Useful source sections:** Explorer: the tree of everything, Properties: the settings panel, Toolbox: assets, with care.
