## Source-grounded context
Tutorials teach one way to do one thing. The Engine API reference tells you everything an object can do, and it is always more current than any video. Beginners avoid it because the pages look dense. They are not hard once you know the layout: five kinds of pages, four kinds of members, and a handful of small tags that answer questions like "can I call this from a LocalScript?" or "will this pause my script?"....
