## Source-grounded context
Every beginner obby ends up with 80 kill bricks, each carrying its own copy of the same Script. Then you want to change the damage, and you edit 80 scripts (or miss three). Tags and attributes fix this: you mark parts with a label like `KillBrick`, store per-part settings like `Damage = 25` on the part itself, and write one server Script that handles them all.
