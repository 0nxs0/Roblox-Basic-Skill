# 06 Characters and Animation — Development Hub

This hub contains 70 new development companions, one for each existing Markdown note in **06 Characters and Animation**. Each links to its source and adds implementation and validation guidance.

## Focus
Use this material to make character motion readable.

## Build loop
1. Name movement states and transition rules; tune one transition at a time against the rig and camera.
2. Handle interruption, respawn, tool use, replication, and animation priority.
3. Test slopes, jumps, interruptions, and multiple observers.
