# 14 Testing and QA — Development Hub

This hub contains 77 new development companions, one for each existing Markdown note in **14 Testing and QA**. Each links to its source and adds implementation and validation guidance.

## Focus
Use this material to make bugs reproducible and releases evidence-based.

## Build loop
1. Record setup, actions, expected and actual results, and first known bad build.
2. Cover platform, network, save, lifecycle, and load; keep private data out of logs.
3. Re-run regressions after fixes and attach evidence.
