This hub contains 88 new development companions, one for each existing Markdown note in **07 AI and Combat**. Each links to its source and adds implementation and validation guidance.

## Focus
Use this material to make combat legible and fair.

## Build loop
1. Separate perception, decision, action, and cooldown state; validate hits before polishing effects.
2. Test latency, repeated inputs, cancels, target switching, and attack cues.
3. Verify hitboxes, damage authority, cooldowns, and balance.
